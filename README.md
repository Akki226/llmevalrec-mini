# LLMEvalRec Mini

A small-scale reproduction of the core idea behind LLMEvalRec:
using LLM-based simulated users to evaluate news recommendation systems.

## Research Question

Can simulated users preserve the relative performance ranking of
different recommendation systems observed with real users?

## Project Status

Phase 1 — Reproduction

## Planned Experiment

- MIND dataset
- Small subset of users
- Multiple recommendation strategies
- LLM-based simulated users
- Multi-day interaction simulation
- Ranking evaluation
- Comparison between simulated and real evaluation
